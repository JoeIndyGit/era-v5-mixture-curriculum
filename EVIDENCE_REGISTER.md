# Evidence Register

| Claim type | Included evidence | Interpretation |
|---|---|---|
| Measured | Nine completed neural micro-proxy runs and result chart | Valid only for pilot-scale directional evidence |
| Published | Public dataset cards and papers supporting source volumes | Demonstrates plausible supply, not local download completion |
| Computed | Mixture totals, Indic tier totals and replay factors | Reproducible from CSV files |
| Proposed | Cleaning thresholds, 1B/3B configurations and acceptance gates | Pre-registered decisions to be tested |
| Not claimed | Completed 1B/3B transformer results or full-scale authorization | Prevents fabricated experimental evidence |

A reviewer should treat the 18% Indic mixture as the leading candidate, not as an experimentally proven full-scale optimum.
