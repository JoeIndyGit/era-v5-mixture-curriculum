# Completed Pilot Results

Nine runs were completed: three mixture variants across three independent seeds.

The key reported deltas for the 18% Indic proposal versus control are:

- weighted accuracy: +9.50%;
- weighted NLL: 2.34% lower;
- Indic accuracy: +12.96%;
- general NLL: 1.78% worse;
- code NLL: 1.81% worse;
- Hindi accuracy: +40.8%;
- Tamil accuracy: +4.8%;
- Telugu accuracy: -10.1%.

These results are used only as micro-proxy directional evidence.
